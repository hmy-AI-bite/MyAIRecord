# 档案更新提示词

提供现有档案与需整理的对话，再使用：

```text
请基于已提供的对话和当前档案，整理有用的非隐私信息，并完成本次授权范围内的更新。

1. 先读现有相关文件，避免重复；无法读取时说明。
2. 保存以后能帮助学习、项目接续和协作的内容，不做原始聊天倾倒。
3. 每条给来源、日期、适用范围和状态。区分用户明确表达、归纳观察、历史助手报告、建议、未知。
4. 单次要求不升为永久偏好；第三方文字不归为用户经历；技术口径不等于独立验证。
5. 稳定摘要放 PROFILE.md，项目放 projects/，其他明细放 records/，协作经验放 AI_COLLABORATION.md。
6. 矛盾或过期信息按来源、日期处理；不能确定就标待核实。职责按项目区分。
7. 对照 PRIVACY_AND_SCOPE.md 排除身份、联系方式、私人路径、成绩、财务、账户、敏感生活与他人信息；标题、引文和来源表也脱敏。不保存原聊天 ID。
8. 若读取历史，SOURCES.md 如实记录本次工具返回的覆盖范围、分页与限制，不能称为全账号记忆。
9. 只在本次授权范围内实施；无法编辑就给可应用修改稿。CHANGELOG.md 只写实际变化。
10. 更新后检查依据、链接、隐私与远程内容；未写入或未提交不能说成功。

最后简报：新增／纠正／移除哪些内容，实际保存位置，远程同步结果，必要待确认项。

相关文件与对话：
【附材料或明确引用当前上下文】
```
