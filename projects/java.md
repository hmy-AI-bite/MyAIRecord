### 答辩风险的处理

本课没讲过 SQLite/JDBC，担心被追问。做法是不删库（删了会丢已做的工作），而是把"要会多少"压到最小：6 类 SQL（建表、登录查询、注册插入、分类搜索、库存扣减、下单写入）+ JDBC 五步，并能解释事务为什么用 `stock >= ?` 条件更新。
