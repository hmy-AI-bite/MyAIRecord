# 纹样工作台（Pattern Studio）

整理：2026-11-24。来源：2026-11-06 的界面视觉稿会话与 11-14 的演示片会话。与 [文物纹样项目](heritage.md) 分工：那份记申报与研究口径，这份记界面的视觉规范与演示片状态。

## 项目状态

- 状态：进行中；视觉稿与期中检查演示片已交付，功能项仍有遗留。
- 形态：后端接口加原生前端，串起上传、修复、线稿、矢量化、平铺预览、导出。
- 交付形式：桌面端视觉稿为主要成果，另附平板与移动端适配稿、空态与失败态稿，共九张。

## 视觉规范（已锁定）

| 项 | 规范 |
| --- | --- |
| 背景 | 白到淡蓝渐变，铺传统纹样线稿暗纹；不要荷花、不要散落装饰 |
| 导航栏 | 首页只保留标识与设置入口 |
| 功能入口 | 悬浮式圆形按钮，常态简洁无装饰 |
| 激活态 | 线稿白鹤环绕按钮外圈旋转 |
| 质感 | 半透明玻璃感，避免花哨描边 |

## 演示片（期中检查）

| 项 | 结果 |
| --- | --- |
| 定稿版本 | 约 57 秒，1080p，12 句同音色配音，背景音乐连续无削波 |
| 前半段 | 纹样破损图修复链路，压缩了等待与静止段，动作段不改帧密度 |

| 片内可核验项 | 模型名与提示词版本、图像尺寸、矢量化输出体积，均出现在画面上 |

## 已验证经验

- 演示片要先按真实动作量锚点（切页、勾选、提交、返回），再切分，凭感觉切一定错位。
- 录屏用分片格式，避免进程被杀导致文件尾没写入、整段打不开。
- 界面背景用项目自己的纹样线稿，比通用装饰元素更统一。
